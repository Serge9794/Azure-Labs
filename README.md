## 🎯 À propos de ce dépôt

Ce dépôt regroupe des **projets pratiques Azure réalisés sur un abonnement réel**.  
Chaque projet documente un scénario d'entreprise concret : infrastructure, sécurité réseau, conteneurs, stockage — avec les commandes exécutées, les captures d'écran du portail Azure et les résultats de tests prouvant le bon fonctionnement.

L'objectif est d'approfondir les compétences Azure au-delà de la certification.
